# Initial website scope

This prototype follows the course document's proposed first version of the Origin Coffee website.

## Included

- Home page introducing the company and its value proposition.
- Company, coffee origin, and process information.
- An illustrative product catalog served by the backend API.
- A contact form with server-side validation.
- Responsive layout for mobile and desktop screens.

## Prototype limitations

- Catalog entries are examples, not confirmed commercial offers.
- Contact requests are kept in process memory and disappear when the server stops. No email is sent.
- Shopping cart, accounts, administration, orders, and persistent storage are outside this first version.
- Do not deploy the contact form for real customer data until persistence, delivery, privacy, and abuse protections are implemented.
